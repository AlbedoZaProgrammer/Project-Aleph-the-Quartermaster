# Project Aleph - The Quartermaster

## Description

Project Aleph is a simple terminal-based task manager.

It allows a user to:
- View tasks
- Add tasks
- Remove tasks

The current version is intentionally minimal and serves as the foundation for future development.

---

## Current Version

v0.1.2

---

## Features

- Maximum of 10 tasks
- Terminal interface
- Add tasks
- Remove tasks
- View tasks

---

## Future Plans

- Save tasks between sessions
- Task priorities
- Recurring tasks
- Graphical interface (GUI)

---

## Requirements

Python 3.13 (or newer)
